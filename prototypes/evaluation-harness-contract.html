        Runner sequence
        
    1. Fetch the live public OpenAPI once; validate it and record SHA-256.
2. Preflight every expected operation, schema, field, enum, response, and scope.
3. If a fixture is stale, stop before agent runs and report STALE_FIXTURE.
4. Run each case three times in an isolated fresh agent session.
5. Read activation and tool traces; inventory final-answer API claims and code blocks.
6. Apply deterministic OpenAPI, safety, side-effect, syntax, and structural assertions.
7. Score routing as correct only when both skill activation and operation selection pass.
8. Emit JSON, JUnit, a GitHub summary, and customer-safe debugging artifacts.
